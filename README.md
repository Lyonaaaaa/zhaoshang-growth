## 🎯 项目概述

### 目标
将招商证券研报中的**成长量化选股策略**完整复现，包括：

1. 7 个核心成长因子的精确计算
2. 30 只股票等权组合的月度调仓
3. 2010 年至今的回测验证
4. 不同股票池（沪深300/中证500/中证1000/国证2000）的增强策略

### 研报核心结论
- **全市场策略**：2010 年起年化收益 **29.18%**，相对中证全指超额 **26.39%**，信息比 **2.23**
- **多维成长补充因子**：Rank IC 均值 6.03%，ICIR 3.24，多空年化 24.95%

### 7 大核心成长因子

| 维度 | 因子 | 研报章节 |
|------|------|---------|
| 成长路径 | 位移路程比、上涨次数占比、回归拟合度 | 三 |
| 成长动能 | 成长加速度、增速时序分位点、时间序列回归 | 四 |
| 未来成长 | 财务指标预测 + 分析师预期上调 | 五 |
| 超预期成长 | SUE / SUR / JOR / 财报超预告 / 单季超预期 | 六 |
| 成长性价比 | 净利润增速 + 综合估值因子（PB/PE/PCF） | 七 |
| 多维成长能力 | 现金流成长、经营效率提升、盈利能力提升 | 八 |
| 低基数效应 | 剔除低基数个股 | 九 |

## ⚠️ 注意事项

### 数据对齐
- 所有财务数据是**累计口径**（年初至报告期末）
- 单季度数据需要**自行计算**：本季度累计 - 上季度累计
- 因子计算时需考虑**滞后披露**：用 `info_date`（公告日）避免前视偏差

### 同比 vs TTM
- **同比**：本期 vs 上年同期
- **TTM**：最近 4 个季度滚动求和
- 因子公式里两者**含义不同**，需分开计算

### 低基数效应
研报第九章专门讨论，必须**剔除低基数个股**：
- 去年单季度净利润 ≤ 0 → 剔除
- 去年单季度营业收入 < 0.75 亿元 → 剔除

### 回测细节
- **调仓频率**：每月第一个交易日
- **交易成本**：双边千分之三
- **持仓数量**：30 只
- **基准**：中证全指（000985.XSHG）
